# Changelog

## 0.1.0

Initial public release.

- Folder-based email activity scanning
- Optional domain or address search across Thunderbird accounts
- Sent, received, reply, and thread counts
- Month-by-month activity
- Current-year vs previous-year comparison
- Message list and preview
- Open original messages in Thunderbird
- Most-touched domain and address suggestions
- Local-only storage and processing
