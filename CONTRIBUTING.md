# Contributing

Issues are welcome for bugs you can reproduce and for feature requests that stay focused on one problem.

Pull requests should stay focused and explain what problem they solve.

Privacy is intentional. Client Email Log runs locally inside Thunderbird. Do not add cloud services, telemetry, or any sending of message data without discussing it first.

## Try a change

1. Open Thunderbird.
2. Open **Add-ons and Themes**.
3. Click the gear icon and choose **Debug Add-ons**.
4. Click **Load Temporary Add-on**.
5. Select `manifest.json` from this repository.

A temporary installation lasts until Thunderbird restarts.
